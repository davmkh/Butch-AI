## How Butch uses AI (shared)

_Two or three sentences: Butch answers from the verified knowledge base first. DeepSeek only
phrases the reply, and answers questions outside the knowledge base from general knowledge. The
facts that change with time (open now, deadline passed) are worked out in code. Without an API
key or if the API fails, Butch answers from the knowledge base alone. Note the limit: general
knowledge answers are not verified, which is why marking them is planned for sprint 3 (T-46)._
